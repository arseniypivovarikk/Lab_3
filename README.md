# AgroMarket React — лабораторная работа

Учебный адаптивный маркетплейс фермерских продуктов на React и Vite. Визуальная тема и сценарии посвящены продаже сельскохозяйственных товаров напрямую от местных производителей.

## Реализовано
- React-компонент приложения и состояние через `useState`.
- Каталог товаров, поиск по названию и региону.
- Фильтрация по категориям и сортировка по цене.
- Добавление товаров в корзину, изменение количества и расчёт суммы.
- Избранное с переключением сердечка.
- Адаптивная вёрстка для мобильных устройств, планшетов и компьютеров.
- Демонстрационное оформление заказа без реальных платежей.
- Семантические HTML-теги, подписи для интерактивных элементов и базовые метаданные.

## Запуск локально
Нужны Node.js и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Проверка production-сборки
```bash
npm run build
npm run preview
```

## Публикация на GitHub
1. Создайте новый репозиторий на GitHub.
2. Загрузите содержимое папки проекта (не сам ZIP).
3. Для GitHub Pages с Vite задайте корректный `base` в `vite.config.js`, если проект опубликован в подпапке репозитория, затем подключите GitHub Actions для сборки и публикации.

## Примечание
Это учебный frontend-прототип. Корзина хранится в состоянии страницы; сервер, база данных, аккаунты и настоящая оплата не подключены.
